About This Page

This is an independent microfrontend application that can be developed, tested, and deployed separately from the host application and other remotes. This page is loaded using Dynamic Module Federation. It demonstrates how microfrontends can be seamlessly integrated into a host application.

Features

  • Standalone Angular components
  • OnPush change detection
  • Modern Angular v best practices
  • Dynamic module federation
  • Independent deployment

Technology Stack

  • Angular v
  • Nx v
  • Dynamic Module Federation
  • Tailwind
  • TypeScript
  • Vite
  • Vitest
